# Documentation du stage

Ce dossier centralise la documentation de la maquette Active Directory multi-sites SBTX.

Les dossiers sont organisés dans l'ordre de réalisation. Chaque étape doit contenir les paramètres utilisés, les captures d'écran, les tests réalisés et les éventuels problèmes rencontrés.

> Ne jamais ajouter de mots de passe, d'adresses IP publiques, de fichiers de configuration sensibles ou de données réelles de l'entreprise.
