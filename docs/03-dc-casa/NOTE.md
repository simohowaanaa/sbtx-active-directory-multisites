# Note — DC-CASA

`DC-CASA` est le premier contrôleur de domaine et serveur DNS de la forêt `ad.sbtx.lab`. Son adresse fixe `192.168.10.10` est utilisée comme résolveur DNS local.

Le contrôleur de domaine du site d'Oujda sera ajouté ultérieurement à cette même forêt ; une seconde forêt n'est donc pas nécessaire.

Deux instantanés VirtualBox sécurisent le travail : un après la configuration de base et un après la création du domaine. Les mots de passe administrateur et DSRM ne sont pas stockés dans ce dépôt.
